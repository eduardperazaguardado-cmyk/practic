Algoritmo SumarHastaMayor500
	Definir numero, resultado Como Entero
	numero = 0
	mientras numero <= 500 Hacer
		Escribir " Ingrese un numero para sumar: "
		Leer resultado
		numero = numero + resultado
		escribir " La suma actual es: ", numero

	finMientras
	
	escribir " !Llegaste al numero final¡ ", numero

	
FinAlgoritmo


El objetivo de este programa es acumular la suma de un número ingresado por el usuario con el resultado de la suma anterior hasta que la suma total sea igual o mayor que 500 y ahí finalizar el bucle.


Definir numero, resultado Como Entero
	numero = 0

Primero definimos 2 variables como entero, el numero que actúa como el valor acumulado y el resultado que es el valor que escribe el usuario para sumar.
Tambien iniciamos con numero = 0 para que al inicio tengamos una base limpia siempre y no tengamos números de mas acumulados.


  mientras numero <= 500 Hacer

Aquí es donde le damos sentido al código ya que aquí le explicamos al programa lo que va a hacer cuando el bucle llegue a determinado valor y se ejecutara el bucle siempre y cuando la condición mientras sea verdadera. En el momento en que el numero sea 500 o mas la condición se vuelve falsa y el programa automáticamente se sale del bucle.


Escribir " Ingrese un numero para sumar: "
		Leer resultado

Aquí es cuando dentro del programa se nos pregunta el valor para sumar y nos leerá el resultado de la suma con el numero del resultado de la suma anterior, esto se repite hasta que el bucle se de por finalizado, es 
decir, hasta que la suma haya llegado al valor 500 o mas.






numero = numero + resultado

Esta asignación es la que se le da al programa para que tome el valor actual (numero) y le sume lo que acaba de escribir el usuario (resultado), y ese nuevo valor lo guardada en la asignación (numero), así el valor anterior no se elimina sino que se incrementa.


finMientras
	
	escribir " !Llegaste al numero final¡ ", numero

	
FinAlgoritmo


Este ya seria el final de el algoritmo, una vez que la suma haya llegado al limite se finaliza el “mientras”, y el “escribir” básicamente es lo que se le pide al programa escribir cuando ya el bucle se de como falso y haya finalizado, se pone ¡Llegaste al numero final! Para confirmar que el objetivo final se cumplió.

Y luego finalizamos el algoritmo con el FinMientras.
